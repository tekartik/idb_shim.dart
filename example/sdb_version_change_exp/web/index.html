SDB: several apps, several versions

Two copies of the same app run below, each in its own frame: two connections of one origin to one database, exactly like two tabs. Open version 1 in A, add a record, then open version 2 in B: A closes itself (its log says why) and B opens at once. Untick "Close on version change" in A and open version 2 there, then version 3 in B: B stays blocked until you press Close in A. Delete the database from one app and the other closes too; that is also how to start over from version 1, a version lower than the database's cannot be opened. The app in a new tab joins in the same way.
